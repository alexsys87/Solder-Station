# T12 Station — программа для ПК

WPF-приложение (.NET 8, Visual Studio 2022) для настройки паяльной станции по USB (виртуальный COM-порт)
или UART: живые показания, режимы, быстрая уставка, все параметры, профили жал, мастер калибровки,
импорт/экспорт и автоматические резервные копии настроек, синхронизация часов, консоль протокола,
светлая и тёмная темы, русский и английский язык интерфейса.

Сборка: открыть `SolderStation.sln` в Visual Studio 2022 (рабочая нагрузка «Разработка классических
приложений .NET») и запустить, или `dotnet build -c Release`.

Подробное описание и протокол — в [README](../README.md#программа-для-пк) в корне репозитория.
